# Instrucciones para agentes

- Leer `README.md` al empezar para entender el propósito y estructura del repositorio.
- Cada vez que se modifique un documento, leerlo entero después del cambio antes de responder.
- Mantener los documentos concisos: evitar duplicar información y quitar secciones que metan ruido.
- Documentar solo software instalado manualmente o decisiones explícitas del usuario; no añadir paquetes base detectados automáticamente salvo petición expresa.
- Preferir APT o Snap frente a otros mecanismos de instalación; usar otros métodos solo si ninguno es adecuado o está disponible.
- Actualizar `ops/README.md` cuando un cambio afecte a los procedimientos para usar el repositorio.
- Actualizar `README.md` cuando proceda.
- Mantener actualizado `CONFIGURACION.md` cuando los cambios del repositorio afecten a la configuración documentada.
- Mantener actualizado `CONFIGURACION_MANUAL.md` cuando los cambios afecten a los ajustes manuales documentados.
- Mantener actualizado `SOFTWARE.md` cuando los cambios del repositorio afecten al inventario de software documentado.
- Mantener actualizado `ansible/README.md` cuando los cambios del repositorio afecten a la configuración Ansible documentada.
